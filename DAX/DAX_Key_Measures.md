# Key DAX Measures

These are the DAX measures used in the two Power BI dashboards developed as part of this project:

* **Customers and Sales Dashboard**
* **Product Performance Dashboard**

Some metrics were previously calculated in SQL as part of the analytical views. For the Power BI dashboards, selected metrics were recalculated using **DAX** to make them dynamic and responsive to filters, slicers, and the current dashboard context.

---

## Customers and Sales Dashboard

### Total Clients

Counts the distinct customers included in the sales data.

```DAX
Total Clients =
DISTINCTCOUNT(Sales[customer_id])
```

### Active Clients

Counts customers who made a purchase within the last 12 months, including New Clients.

```DAX
Active Clients =
VAR ReferenceDate =
    MAX(Sales[Order_date])
VAR CutoffDate =
    EDATE(ReferenceDate, -12)
VAR CustomersTable =
    ADDCOLUMNS(
        VALUES(Clients[customer_id]),
        "LastPurchase",
            CALCULATE(
                MAX(Sales[Order_date])
            )
    )
RETURN
    COUNTROWS(
        FILTER(
            CustomersTable,
            [LastPurchase] >= CutoffDate
                && [LastPurchase] <= ReferenceDate
        )
    )
```

### New Clients

Counts customers whose first purchase occurred within the previous 12 months.

```DAX
New Clients =
VAR ReferenceDate =
    MAX(Sales[Order_date])
VAR CutoffDate =
    EDATE(ReferenceDate, -12)
VAR CustomersTable =
    ADDCOLUMNS(
        VALUES(Clients[customer_id]),
        "FirstPurchase",
            CALCULATE(
                MIN(Sales[Order_date]),
                REMOVEFILTERS(Sales[Order_date])
            )
    )
RETURN
    COUNTROWS(
        FILTER(
            CustomersTable,
            [FirstPurchase] >= CutoffDate
                && [FirstPurchase] <= ReferenceDate
        )
    )
```

### Average Order Value

Calculates the average revenue generated per order.

```DAX
Average Order Value =
DIVIDE(
    [Customer Revenue],
    DISTINCTCOUNT(Sales[order_number]),
    0
)
```

### Average Monthly Expense

Calculates the average monthly spending per customer based on their purchasing lifespan.

```DAX
Average Monthly Expense =
AVERAGEX(
    VALUES(Clients[customer_id]),
    VAR FirstPurchase =
        CALCULATE(MIN(Sales[Order_date]))
    VAR LastPurchase =
        CALCULATE(MAX(Sales[Order_date]))
    VAR LifespanMonths =
        DIVIDE(
            DATEDIFF(FirstPurchase, LastPurchase, DAY),
            30,
            0
        )
    VAR TotalSales =
        CALCULATE(SUM(Sales[sales_amount]))
    RETURN
        IF(
            LifespanMonths < 1,
            TotalSales,
            DIVIDE(TotalSales, LifespanMonths, 0)
        )
)
```

### Revenue Generated

Calculates total revenue within the current filter context.

```DAX
Revenue_sales =
SUM(Sales[sales_amount])
```

### Cumulative Revenue Rank

Calculates cumulative revenue based on the ranking of the selected age groups.

```DAX
Cum_revenue_rank =
VAR RankingActual =
    [Ranking_age]
RETURN
SUMX(
    FILTER(
        ALLSELECTED(Clients[Age_group]),
        [Ranking_age] <= RankingActual
    ),
    [Revenue_sales]
)
```

### Cumulative Revenue %

Calculates the cumulative percentage of revenue generated by the selected age groups.

```DAX
%_Cum_revenue =
DIVIDE(
    [Cum_revenue_rank],
    CALCULATE(
        [Revenue_sales],
        ALLSELECTED(Clients[Age_group])
    )
)
```

## Product Performance Dashboard

### Total Products

Counts the products included in the product catalog.

```DAX
Products # =
DISTINCTCOUNT(Products[product_name])
```

### Products with Sales

Counts products that generated revenue during the analyzed period.

```DAX
Products with Sales =
CALCULATE(
    DISTINCTCOUNT(Products[product_id]),
    Products[total_revenue] > 0
)
```

### Items Sold

Calculates the total number of units sold.

```DAX
Items Sold =
SUM(Sales[quantity])
```

### Average Price

Calculates the average selling price per unit.

```DAX
Average Price =
DIVIDE(
    SUM(Sales[sales_amount]),
    SUM(Sales[quantity])
)
```

### Average Margin

Calculates the overall margin as total margin divided by total revenue.

```DAX
Margin % =
DIVIDE(
    [Total Margin],
    [Total Revenue]
)
```

### % of Total Revenue

Calculates the percentage of total revenue generated by the selected products within the current filter context.

```DAX
Revenue % Total =
DIVIDE(
    [Total Revenue],
    CALCULATE(
        [Total Revenue],
        ALLSELECTED(Products)
    )
)
```

### Cumulative Revenue %

Calculates the cumulative percentage of revenue based on the selected product ranking.

```DAX
Cumulative Revenue % =
DIVIDE(
    [Cumulative Revenue],
    CALCULATE(
        [Total Revenue],
        ALLSELECTED(Products)
    )
)
```

### Product Rank by Revenue

Ranks products according to their revenue contribution, dynamically responding to the selected filters.

```DAX
Product Revenue Rank =
RANKX(
    ALLSELECTED(Products),
    CALCULATE([Total Revenue]),
    ,
    DESC,
    DENSE
)
```
